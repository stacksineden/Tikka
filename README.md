# Tikka build pack

Everything Claude Code needs to build Tikka version one.

1. Create the repo and copy this whole folder into its root (CLAUDE.md stays at the root).
2. Open Claude Code in the repo. It reads CLAUDE.md automatically.
3. Paste the M0 prompt from docs/BUILD_PROMPTS.md. When its checks pass, paste M1, and so on.

- CLAUDE.md: the rules every session follows (stack, structure, rules that must never break, brand in code)
- docs/PRD.md: what version one does, screen by screen, with edge cases
- docs/TECH_PLAN.md: data model, the claim function, WhatsApp and its queue, codes, reviews, marketplace, payments, link activity
- docs/BUILD_PROMPTS.md: the eleven milestones (M0–M10), in order
- design/: tokens (JSON + CSS), brand book, logos, component references, and the approved card prototype
