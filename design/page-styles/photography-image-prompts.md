# Photography style: image prompts

Save each image into `design/page-styles/img/` with the file name shown. The mockup
(`photography.html`) picks it up on reload. JPG, about 2000px on the long side.

Add this to every prompt so the set looks like one photographer's work:
> Shot by a high-end Lagos portrait studio. Nigerian subjects, rich dark skin rendered beautifully, soft directional key light, deep shadows, warm champagne and ink tones, fine film grain, editorial, luxurious, no text, no watermark.
