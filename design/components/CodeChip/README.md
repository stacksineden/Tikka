# CodeChip

A redeem code set in Space Mono with a copy button, dashed like a ticket edge.

**Consumer provides:** the code. Default size uses `code-lg` (card, redeem screen, the WhatsApp card); `tk-code--sm` uses `code` (tables).

- Codes are a two-letter business prefix, a hyphen, and five characters from `ACDEFGHJKMNPQRTUVWXY34679`, the last a check character, so typos are caught offline.
- Never break a code across lines.
