# RarityBadge

A pill naming a card's tier with its word and one to three pips, so rarity never depends on colour alone.

**Consumer provides:** the tier (`common`, `rare`, `legendary`) as a modifier class and its label. Thank-you cards use the common style with the label "Thank-you".

- Use on the back of a Tikka, in the "What's in this drop" list and in the dashboard's reward column.
- Text is always `on-gold`; fills are `rarity-common`, `rarity-rare` and `rarity-legendary`, the same on light grounds and on `night`.
- Don't use rarity colours for anything but rarity.
