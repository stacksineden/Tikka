# DropContents

The "What's in this drop" box on the claim page, shown before the claim so a modest card feels like a fair chance, not bait.

**Consumer provides:** each reward with its count and tier, in order legendary → rare → common, plus the eligibility line ("One per WhatsApp number", "New customers only").

- Always show it above the claim button.
- Counts are mono and gold; rewards are plain `body` text.
- Don't hide the thank-you tier or call it "nothing".
