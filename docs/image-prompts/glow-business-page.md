Save each image as WebP in `public/mock/glow/` with the exact file name. Each one shows on
usetikka.com/glowstudio as soon as the file is there (no restart needed). Until then the page
falls back to the brand colour.

women and men, modern Lagos skin studio** (cream walls, light wood, plants, soft towels, muted
plum and rose accents to match the brand colour #9C3B5C). No text, logos or watermarks in the
image. No visible brand names on products.
